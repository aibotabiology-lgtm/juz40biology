# BIO APP

Биологиядан ҰБТ-ға дайындық платформасы. Автор: Айбота Екпінқызы.

- `index.html` — сайт (конспект, Биокод, BIOLAB, ҰБТ тест)
- `t/`, `q/`, `s/`, `th/` — тақырыптар, сұрақтар банкі, зертханалар, суреттер
- `supabase/setup.sql` — дерекқор кестелері мен қорғаныс ережелері
- `supabase/tg-auth.ts` — Telegram арқылы кіру (Supabase Edge Function `tg-auth`)

Хостинг: Netlify (https://biologyubt.netlify.app), сборка қажет емес.
